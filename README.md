One original one-line joke about crypto trading life, written for the make.fun Laugh Track contest. The joke has to land in a single line, between 1 and 200 characters, with no setup beyond the line itself.

## Entry

> I bought the dip at $60K. It dipped again, dug a basement, and now my portfolio pays rent underground.

## How to run

```bash
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library. It writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that variable is set) and asserts the entry stays inside the 1-200 character gate before writing.
